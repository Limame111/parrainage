# 📄 Fichiers CSV d'exemple

Ce dossier contient des fichiers CSV d'exemple pour tester l'application de parrainage.

## 📋 Fichiers disponibles

- **`filleuls-l1.csv`** : Liste de 20 étudiants L1 (filleuls)
- **`parrains-l2.csv`** : Liste de 20 étudiants L2 (parrains)

## 🎯 Format

Chaque fichier contient une liste de noms au format :
```
Nom Prénom
Nom Prénom
...
```

Une ligne = un étudiant

## 💡 Utilisation

1. Ouvrez l'application dans votre navigateur
2. Cliquez sur "Lancer le Parrainage"
3. Sélectionnez `filleuls-l1.csv` pour les filleuls
4. Sélectionnez `parrains-l2.csv` pour les parrains
5. Cliquez sur "Lancer le Parrainage"

Les résultats seront affichés avec des animations spectaculaires ! 🎬

## ✏️ Créer vos propres fichiers

Pour utiliser vos propres listes d'étudiants :

1. Créez un fichier `.csv` (ou `.txt`)
2. Ajoutez un nom par ligne au format "Nom Prénom"
3. Assurez-vous que le fichier est encodé en UTF-8
4. Chargez-le dans l'application

**Astuce** : Vous pouvez créer les fichiers avec Excel, Google Sheets, ou n'importe quel éditeur de texte.
